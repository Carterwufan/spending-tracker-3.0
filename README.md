# Spending Tracker

## Local use

1. Install dependencies with `pip install -r requirements.txt`.
2. In `.env`, set a long random `SECRET_KEY` and a strong `APP_PASSWORD`.
3. Start the web app with `python app.py`.

The app listens on port 5000 and accepts connections from other devices on your network. Keep the computer running while you use it.

## Host on Render

The included `render.yaml` configures a paid, always-on Render web service with HTTPS and a persistent disk for SQLite. Render's free web services can sleep, so they are not configured here.

1. Create a **private** GitHub repository for this project. Make sure `.gitignore` is included before adding files. It excludes `.env`, the local virtual environment, and expense data; never commit secrets or your database.
2. Push the project files to GitHub.
3. In Render, create a new **Blueprint** and connect the repository. Render reads `render.yaml`; keep the paid `starter` plan and persistent disk to avoid sleeping and losing SQLite data on redeploy.
4. When prompted, provide a strong, unique value for `APP_PASSWORD`. `SECRET_KEY` is generated by Render, and `DB_PATH` points to the persistent disk. Do not set `LOCAL_DEV` in Render.
5. After deployment, open the Render HTTPS URL on your phone, sign in, and use your browser's “Add to Home Screen” or “Install app” option.

The service uses one Gunicorn worker because it stores data in SQLite on a persistent disk. The disk is separate from the repository, so the existing local `expenses.db` and `expenses.txt` are intentionally not uploaded or imported. Back up the Render disk regularly; the disk is where expense records are stored.

For local phone testing, connect the phone and computer to the same Wi-Fi, run `ipconfig` on Windows to find the computer's IPv4 address, then visit `http://<computer-ip-address>:5000`. Local HTTP is for testing only; use Render's HTTPS URL for secure access and PWA installation.
